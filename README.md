# EcoLanyards

Sito web statico per **EcoLanyards** – lanyards e badge personalizzati (produzione diretta).

## Contenuti

- **Home / Lanyards**: 10 prodotti (PET riciclato, raso, poliestere, tubolare)
- **Badge**: 10 modelli (PVC, similpelle, plastica rigida/colorata)
- Scheda prodotto con descrizione, form “Richiedi Informazioni” e prodotti correlati
- Contatti: `commerciale@ecolanyards.it` · telefono **335 810 9363**
- Pulsante flottante: **Chiama** o **WhatsApp** (stesso numero)

## Anteprima

Apri `index.html` nel browser oppure abilita **GitHub Pages** sul branch `main` (Settings → Pages → Deploy from branch `main` / root).
